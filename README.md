# Tenir Hotels Website

Repository for the Tenir Hotels website.

## Project structure

- `V1/public_html/` — legacy website (current production version).
- `V2/` — new website, planned on Laravel 12 and Filament 4.

## Development

V1 is preserved as-is for reference and maintenance.

V2 will be developed separately without modifying the legacy application.

## Deployment

Production deployment of V1 uses the contents of `V1/public_html/`.

V2 deployment instructions will be added when the new application is ready.
